# История заказов

Интерактивный дашборд на Vue.js и D3.js по учебному датасету первой недели, вариант C. Данные охватывают сентябрь 2021 — август 2026.

[Открыть сайт](https://adelyasalakhova.github.io/week-4/).

Можно выбрать год или отдельный месяц, посмотреть количество заказов, сумму трат, среднюю скидку и экономию. Рейтинги показывают товары по частоте заказов, количеству единиц и расходам; выбор категории фильтрует оба рейтинга. При наведении доступны подробные значения.

Заказы считаются по уникальным идентификаторам. Траты и скидки учитывают только доставленные заказы. Средняя скидка выражена в рублях на единицу товара и учитывает товары без скидки. Доставка и упаковка включены в общие траты, но показаны отдельно от товаров и не участвуют в расчёте скидки.

## Локальный запуск

Нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Проверка расчётов и сборка:

```sh
npm test
npm run build
npm run preview
```

## Файлы

- `index.html`, `styles.css`, `app.js` — страница, оформление и интерфейс Vue.
- `charts.js` — графики D3.
- `analytics.js` — фильтрация и расчёт показателей.
- `data/dashboard.json` — месячные показатели и сводка по товарам.
- `scripts/prepare_data.py` — подготовка данных из исходного CSV.

Исходный CSV остаётся локальным и не входит в репозиторий. Чтобы обновить сводку, поместите один исходный CSV в папку проекта и выполните `python scripts/prepare_data.py` либо передайте путь к файлу первым аргументом. В опубликованных данных нет адресов доставки и исходных идентификаторов заказов.
