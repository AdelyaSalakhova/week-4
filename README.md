# Заказы пользователей

Интерактивный дашборд на Vue.js и D3.js с данными о заказах за сентябрь 2021 — август 2026.

[Открыть сайт](https://adelyasalakhova.github.io/week-4/).

В селекторе периода год переключается стрелками, а месяц выбирается в сетке. Кнопки «Весь год» и «Весь период» возвращают более широкий период. Дашборд показывает количество заказов, сумму трат, среднюю скидку и экономию. При наведении на количество заказов показаны доставленные и отменённые заказы отдельными строками. Рейтинги показывают товары по частоте заказов, количеству единиц и расходам; выбор категории фильтрует оба рейтинга. В рейтингах есть изображения товаров из учебного архива Items; при наведении доступны подробные значения и увеличенное изображение.

Заказы считаются по уникальным идентификаторам. Траты и скидки учитывают только доставленные заказы. Средняя скидка выражена в рублях на единицу товара и учитывает товары без скидки. Доставка и упаковка включены в общие траты, но показаны отдельно от товаров и не участвуют в расчёте скидки.

## Локальный запуск

Нужен Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev
```

Проверка расчётов и сборка:

```sh
npm test
npm run build
npm run preview
```

## Файлы

- `index.html`, `styles.css`, `app.js` — страница, оформление и интерфейс Vue.
- `charts.js` — графики D3.
- `select-control.js` — единое оформление и управление выпадающими списками.
- `period-picker.js` — выбор года и месяца в компактной сетке.
- `analytics.js` — фильтрация и расчёт показателей.
- `data/dashboard.json` — месячные показатели и сводка по товарам.
- `scripts/prepare_data.py` — подготовка данных из исходного CSV.
- `assets/items/`, `images.js` — изображения товаров и их подключение.
- `scripts/prepare_images.py`, `data/image-sources.json` — сопоставление с архивом Items. Названия бренда «Из Груши» и «Из Лавки» в учебных материалах приведены к одному варианту; различия самих товаров сохраняются.

Исходный CSV остаётся локальным и не входит в репозиторий. Чтобы обновить сводку, поместите один исходный CSV в папку проекта и выполните `python scripts/prepare_data.py` либо передайте путь к файлу первым аргументом. В опубликованных данных нет адресов доставки и исходных идентификаторов заказов.

Изображения можно обновить командой `python scripts/prepare_images.py PATH_TO_ITEMS_ZIP` после подготовки сводки. В проект копируются только картинки товаров, встречающихся в данных.
